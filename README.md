# 文字格斗游戏 🎮

一个基于控制台（Console）的文字格斗游戏，使用纯 Java 编写，无需任何第三方依赖。

## 功能特性

- **账号系统** — 支持注册、登录、忘记密码，含验证码校验和登录次数限制（3 次错误后锁定账号）
- **角色创建** — 自由分配 20 点属性（生命值/攻击力/防御力/蓝条）
- **蓝条系统** — 技能消耗 MP 而非 HP，战斗后回复 30% 蓝量
- **回合制战斗** — 四种玩家行动：
  - 普通攻击 — 基础伤害
  - 强力一击 — 消耗 10 MP，造成 1.8 倍伤害
  - 生命汲取 — 消耗 10 MP，恢复随机生命值
  - 使用道具 — 使用背包中的回血道具恢复生命值
- **多种敌人** — 战士（猛击）、刺客（快速攻击·二连击）、坦克（防御姿态·减伤）、法师（火球术·高爆发）
- **成长系统** — 每胜利 3 场获得属性提升（含蓝量上限 +10），敌人也会随战斗次数变强
- **道具系统** — 战斗胜利后 1/3 概率获得回血道具（桃子/煎蛋/花酿鸡/黑白鲈鱼/白玉汤），可在玩家回合使用
- **结算系统** — 显示总胜场数

## 快速开始

### 环境要求

- JDK 17+

### 编译与运行

```bash
# 编译
javac -d out src/App.java src/com/itheima/**/*.java

# 启动游戏（含登录界面）
java -cp out App
```

启动后进入登录界面：

```
┌───────────────────────────┐
   🎮 欢迎来到文字格斗游戏 🎮
└───────────────────────────┘
请选择操作：1登录  2注册  3忘记密码  4退出
```

## 操作流程

1. **注册账号** — 输入用户名（3-16 位字母数字）、密码（3-8 位，需包含字母和数字）和手机号
2. **登录** — 输入密码+验证码，3 次错误后账号锁定
3. **忘记密码** — 通过手机号验证后重置密码
4. **分配属性** — 20 点自由分配（含蓝条选项）
3. **分配属性** — 20 点自由分配
4. **开始战斗** — 轮流选择技能与敌人对战
5. **继续/退出** — 每场战斗后可选择继续或退出

## 项目结构

```
src/
├── App.java                          # 入口类
└── com/itheima/
    ├── domain/                       # 领域模型
    │   ├── Character.java            # 角色基类（HP/攻击/防御/回血/受伤）
    │   ├── HeroCharacter.java        # 玩家角色（继承 Character，含技能列表、MP、背包）
    │   ├── EnemyCharacter.java       # 敌人角色（继承 Character，含防御姿态减伤）
    │   ├── Consumable.java           # 消耗品道具（名称/回血量）
    │   └── User.java                 # 用户账号（含手机号）
    └── ui/
        ├── Login.java                # 登录注册系统
        └── FightingGame.java         # 游戏主循环与战斗逻辑
```

## 类图

```
Character (基类)
├── HeroCharacter  — 玩家角色，拥有技能列表、MP 和背包
└── EnemyCharacter — 敌人角色，拥有特色技能和防御状态
```
