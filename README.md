# 文字格斗游戏 🎮

一个基于控制台（Console）的文字格斗游戏，使用纯 Java 编写，无需任何第三方依赖。

## 功能特性

- **账号系统** — 支持用户注册、登录，含验证码校验和登录次数限制（3 次错误后锁定账号）
- **角色创建** — 自由分配 20 点属性（生命值/攻击力/防御力）
- **回合制战斗** — 三种玩家技能：
  - 普通攻击 — 基础伤害
  - 强力一击 — 消耗 10 HP，造成 1.8 倍伤害
  - 生命汲取 — 消耗 10 HP，恢复随机生命值
- **多种敌人** — 战士（猛击）、刺客（快速攻击·二连击）、坦克（防御姿态·减伤）、法师（火球术·高爆发）
- **成长系统** — 每胜利 3 场获得属性提升，敌人也会随战斗次数变强
- **结算系统** — 显示总胜场数

## 快速开始

### 环境要求

- JDK 17+

### 编译与运行

```bash
# 编译
javac -d out src/App.java src/com/itheima/**/*.java

# 启动游戏（含登录界面）
java -cp out App
```

启动后进入登录界面：

```
┌───────────────────────────┐
   🎮 欢迎来到文字格斗游戏 🎮
└───────────────────────────┘
请选择操作：1登录  2注册  3退出
```

## 操作流程

1. **注册账号** — 输入用户名（3-16 位字母数字）和密码（3-8 位，需包含字母和数字）
2. **登录** — 输入密码+验证码，3 次错误后账号锁
3. **分配属性** — 20 点自由分配
4. **开始战斗** — 轮流选择技能与敌人对战
5. **继续/退出** — 每场战斗后可选择继续或退出

## 项目结构

```
src/
├── App.java                          # 入口类
└── com/itheima/
    ├── domain/                       # 领域模型
    │   ├── Character.java            # 角色基类（HP/攻击/防御/回血/受伤）
    │   ├── HeroCharacter.java        # 玩家角色（继承 Character，含技能列表）
    │   ├── EnemyCharacter.java       # 敌人角色（继承 Character，含防御姿态减伤）
    │   └── User.java                 # 用户账号
    └── ui/
        ├── Login.java                # 登录注册系统
        └── FightingGame.java         # 游戏主循环与战斗逻辑
```

## 类图

```
Character (基类)
├── HeroCharacter  — 玩家角色，拥有技能列表
└── EnemyCharacter — 敌人角色，拥有特色技能和防御状态
```
